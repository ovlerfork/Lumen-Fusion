Lumen Fusion — 安装 / Installation

需要 Apple Silicon Mac，macOS 15 或更新版本。
Requires an Apple Silicon Mac running macOS 15 or later.

1. 升级前，从旧版菜单栏选择 Quit，完全退出应用。
   When upgrading, quit the old app from its menu bar first.

2. 将 Lumen Fusion.app 拖到旁边的 Applications 文件夹。
   Drag Lumen Fusion.app to the Applications folder beside it.

3. 弹出这个磁盘镜像，然后从 Applications 打开 Lumen Fusion。
   Eject this disk image, then open Lumen Fusion from Applications.

这是菜单栏应用，不一定显示 Dock 图标或主窗口。
从菜单栏打开管理页面，设置管理员账号并与 Moonlight / VoidLink 配对。
This is a menu-bar app. Open its web interface from the menu bar to set up
an administrator account and pair your Moonlight / VoidLink client.

首次运行 / First launch

本预览版使用 ad-hoc 签名，未做 Apple 公证。如果 macOS 提示无法验证开发者，
确认下载来源后，在“系统设置 → 隐私与安全性”中使用该应用的“仍要打开”。
This preview is ad-hoc signed, not notarized. If macOS cannot verify its developer,
verify the download source and use the app-specific Open Anyway action in
System Settings → Privacy & Security.

按提示授予“录屏与系统录音”和远程键鼠控制所需的“辅助功能”权限。
系统要求退出并重新打开时，请执行该操作。升级后可能需要重新授权。
Grant Screen & System Audio Recording, and Accessibility for remote keyboard/mouse
control. Relaunch when macOS asks. An update may require authorization again.

系统音频已经内置，无需安装 BlackHole。音频设备留空或填写 system。
Built-in system audio needs no BlackHole driver. Leave the audio device blank
or use system.

自动启动 / Launch at login

自动启动默认关闭。安装到 Applications 后，在菜单栏的登录启动设置中勾选启用。
状态为“需要批准”时，打开系统登录项设置，由你确认允许。
可随时取消勾选；应用不会在启动时偷偷重新启用。
Launch at login is off by default. After installing in Applications, enable it
in the menu-bar login settings. If approval is required, open the system Login
Items settings and approve it yourself. You can disable it at any time.

按本地屏幕状态保留远程桌面 / Adaptive virtual desktop

此功能默认不改变旧配置。在管理页面“配置 → 音频/视频”中开启虚拟显示器，
将布局设为“自适应”。有其他可用本地屏幕时，默认在断开后移除虚拟副屏；
没有其他屏幕时，暂停音视频但保留桌面，供继续连接时复用。
In Configuration → Audio/Video, enable the virtual display and select Adaptive.
With a usable local screen, disconnect removes the virtual extension by default.
Without another screen, disconnect stops media while retaining the desktop for Resume.

保留的桌面持续可用，直到明确结束会话、手动释放，或本地屏幕策略将其移除。
菜单栏“Virtual Desktop…”可查看状态并释放无人使用的桌面。
所选闲置睡眠保护在保留期间持续生效，不会解锁 Mac。
A retained desktop remains available until explicitly ending the session, releasing
it, or removal by the local-screen policy. Use Virtual Desktop… in the menu bar
to inspect/release an idle desktop. The selected idle-sleep protection remains
active during retention. It does not unlock the Mac. Lid-close, manual, thermal
and low-battery sleep remain system decisions.

部分显示器关闭后仍被系统报告为可用，可在同一配置区手动覆盖本地屏幕检测。
恢复时保留原桌面模式；需要改变桌面分辨率或刷新率时，结束桌面会话再连接。
Some powered-off monitors still appear available; the same settings group provides
a detection override. Resume preserves the desktop mode; end and reconnect the
session when a different desktop resolution or refresh rate is needed.

可选性能对比 / Optional latency comparisons

安装后可运行 benchmark-latency.command，或在终端运行：
bash "/Applications/Lumen Fusion.app/Contents/Resources/benchmark-latency.command" --repeat 2
测试结果写入桌面的新目录，不修改应用、配置、配对、登录项或虚拟桌面。
对比前先断开正在运行的媒体串流；空闲主机可保持运行以保留桌面。
此测试测量合成画面的编码耗时，不等于抓屏、网络和客户端在内的总延迟。
每组测试结束后会解码检查输出；同时查看实际 FPS、p95/p99 和漏过的时隙，
不要仅依据最低值选择设置。完整选项通过脚本 --help 或应用 --benchmark --help 查看。
Run benchmark-latency.command after installation, or use the command above.
Results are written to a new Desktop folder without editing host settings or state.
Disconnect active media streams first; an idle host may remain to retain a desktop.
This synthetic encoder test is not capture/network/client latency. It validates
output by decoding after timing. Compare FPS, tail latency and missed ticks too.

管理页面提供 VideoToolbox 编码器选择、速度/功耗偏好、H.264 熵编码，以及
音频/视频页的采集队列深度。默认行为不变；实验不会自动应用“最佳”配置。
真实串流可在“高级设置”启用性能日志，用完后关闭，比较两边保持同一日志设置。
The web UI exposes reversible VideoToolbox and capture-queue experiments. Defaults
are unchanged. Advanced settings provide opt-in real-stream performance logging;
disable it after comparisons and use the same logging setting on both sides.

保留现有配置和配对 / Existing settings and pairing

配置继续位于 ~/.config/lumina。替换 .app 不会清空它。
不要使用旧的 ~/.local/bin/lumen-fusion 命令测试新 .app，它可能指向旧安装。
Settings remain in ~/.config/lumina. Replacing the .app does not erase them.
The legacy ~/.local/bin/lumen-fusion command may still run an older installation.

无需终端安装命令、Homebrew、sudo，也不需要关闭 SIP、AMFI 或 Gatekeeper。
No terminal installer, Homebrew or sudo is required. Do not disable SIP, AMFI
or Gatekeeper.
